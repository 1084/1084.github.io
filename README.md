# johnhubert.llc

Public website of John Hubert LLC, served by GitHub Pages at https://johnhubert.llc/.

- `index.html` — storefront: projects, guides, about
- `privacy.html` — privacy policy for the site and all published apps
- `guides/` — written guides, one HTML file each
- `vitamin-village/` — the Vitamin Village PWA (installable; bump `CACHE_NAME` in `sw.js` after every edit)
- `CNAME` — custom domain for GitHub Pages (do not delete)

This repository must stay **public** for GitHub Pages to serve it on a free account.
Never commit secrets or private notes here.
